# realm-au-donations

Australian political donations — the [AEC Transparency Register](https://transparency.aec.gov.au/)'s
annual disclosure returns (1998–99 onward) as a governed, graph-queryable relational store
for Embabel worlds.

```cypher
// Who has this entity given money to, and when?
MATCH (q:DonationQuery {name:'…'})-[:HAS_ENTITY]->(e:DonationEntity)-[:MADE_DONATION]->(d:Donation)
RETURN d.financial_year, d.made_on, d.value ORDER BY d.made_on DESC

// Chain outward: the ABN joins the ABR and Wikidata; the name joins live AusTender
// contracts and the lobbyist register (realm-gov-au); ownership and press via realm-diffbot.
```

## This is a PROVISIONED-STORE realm

The AEC publishes bulk CSV files with no query API, so this realm ships the recipe for its
own backing database and declares the datasource it expects (`sql/datasources.yml` →
`au_donations`). Provisioning is three commands:

```bash
docker compose up -d --wait
python3 scripts/load-aec.py            # downloads AllAnnualData.zip (~2.5 MB), normalizes, loads
export AU_DONATIONS_PASSWORD=read-only-demo
```

The loader is stdlib-only Python (SQL goes through `docker exec psql` — nothing to install).
For a non-Docker Postgres (brew, Neon, RDS): `python3 scripts/load-aec.py --psql "psql <url>"`.

Loaded shape (as of the 2024–25 release): **42,370 entities · 20,973 returns · 126,043
receipts · 66,260 donations · 14,679 debts.** The raw export links records only by
`(Financial Year, free-text Name)`; the loader's normalization pass resolves names into one
`entities` table so every money flow is a real foreign key — which is exactly what the
schema miner turns into graph edges.

## Read-only, three ways

1. `sql/datasources.yml` contains no `readOnly: false` — the platform refuses every write
   path at its single SQL choke point.
2. The platform's read path sets the JDBC session read-only hint (enforced by PostgreSQL).
3. The datasource connects as `demo_reader`, a SELECT-only database role
   (`sql/schema.sql`) — the credential itself cannot write, whatever asks.

## Provenance of the realm YAML

`types/` and `producers/` were **generated by the platform's schema miner** against the
loaded database, then curated. The git history keeps that honest: the first commit of those
files is the miner's output verbatim; the curation diff on top is the human contribution
(naming, descriptions, the query anchor, caching). Governance ships `mode: open` with the
full column lists pre-written under `expose:` — governing a deployment is pruning lines and
flipping one keyword, never authoring from scratch.

## Requirements & data terms

- An Embabel `me` build with the v2 `sql` producer (the RDBMS-as-graph branch, #827).
- AEC Transparency Register data is published by the Australian Electoral Commission;
  reuse per the terms on aec.gov.au (CC BY where stated). Annual returns are released the
  first business day of February; re-run the loader to refresh. This realm reports what
  entities disclosed to the AEC; a disclosure is a sourced fact, never a finding.
